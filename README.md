# Bruno Fitness V1

PWA para iPhone, sem necessidade de Xcode.

Inclui:
- Dashboard com metas de 80 kg e cintura < 90 cm
- Treino Push / Pull / Legs / Upper / Lower
- Registo de kg, reps, RIR e séries concluídas
- Histórico de sessões
- Plano alimentar de referência (~2200 kcal / 175 g proteína)
- Marcação de refeições
- Registo de água
- Peso, cintura, peito, braço e coxa
- Histórico e gráfico de evolução
- Dados guardados localmente no dispositivo
- Service Worker para funcionamento offline após carregamento/instalação

## Instalação
Para ter comportamento de app no iPhone, publique esta pasta num endereço HTTPS e abra no Safari. Depois use Partilhar > Adicionar ao ecrã principal.

## Importante
O teu Mac com macOS Catalina não precisa de Xcode para esta V1. A V2 poderá acrescentar Apple Health, notificações, sincronização e uma versão nativa/App Store.
